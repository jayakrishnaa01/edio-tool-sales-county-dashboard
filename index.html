Data source & settings

Google Sheet Paste the link of your sheet (shared as “Anyone with the link”, or published to the web as CSV). The dashboard re-reads it on every sync.
  1. Open the sheet → Share → General access → Anyone with the link (Viewer), or File → Share → Publish to web → CSV.
  2. Paste the link above and press Connect.
  3. Expected columns: Date of Tool Purchased, Customer Name, Address, Mobile Number. Extra columns like Tool Type, Salesperson or Quantity are picked up automatically.
If your browser refuses to read the sheet while the dashboard is opened as a local file, download the sheet once (File → Download → CSV) and upload it here — everything else works exactly the same.
Auto refresh The sheet is polled in the background. The dashboard is only as fresh as the last sync — the exact time is always shown in the header. Map counting Unknown and conflicting records are never placed on a map. Manual corrections
